# Brickmaster 설계 메모

벽돌깨기 × 로그라이트 모바일 게임. 한 손 세로 화면, 1턴 10~30초, 1판 10~20분.

## 핵심 루프
1. 조준 → 발사 → 공이 튕기며 벽돌을 부숨
2. 벽돌 파괴 → 경험치 → 레벨업 → 능력 카드 3장 중 1장 선택 (판 안 성장)
3. 턴이 끝나면 벽돌이 한 줄 내려옴. 빨간 선에 닿으면 체력 -1 (보스는 -2)
4. 10턴마다 보스. 잡으면 챕터 클리어 + 골드
5. 판이 끝나면 골드 → 작업실에서 영구 강화 (판 밖 성장) → 다음 판

| 영구 강화 6종 | 시작 공, 기본 화력, 장갑, 훈련, 선행 연구, 수집가 | `20-data.js` `META` |
| 특수 벽돌 | 폭탄(주변 폭발), XP 상자(즉시 레벨업), 강철(체력 3배, 골드), 슬라임(깨지면 2개로 분열), 보스 | `40-state.js` `spawnRow` |

## 밸런스
모든 수치는 `src/js/00-config.js`의 `BAL`에 있다.

봇 시뮬레이션(실제 게임 로직을 헤드리스로 돌림, 영구 강화 없음, 12판 기준):
- 무작위 조준 봇: 중앙값 38턴, 범위 27~81턴
- 가장 낮은 벽돌 조준 봇: 중앙값 32턴, 범위 26~78턴
- 일찍 끝나는 판은 대부분 26~27턴: 1챕터 보스를 못 잡고 보스가 바닥에 닿는 경우
- 오래 가는 판은 분열 + 연쇄 번개 + 화염탄 조합. 지배 전략이 되지 않는지 실제 플레이로 확인 필요

사람은 벽 반사를 노려서 봇보다 잘할 것으로 예상. 실측 데이터로 다시 맞춰야 한다.

## 다음 후보

- 카드 희귀도(일반/희귀/영웅)와 리롤 1회
- 일일 미션, 출석 보상
- 보스 패턴: 이동, 보호막, 하수인 소환
- 실제 광고 SDK와 앱 포장(Capacitor), 분석 이벤트(턴, 사망 원인, 카드 선택률)

## 빌드
```
node brickmaster/build.js   # src/shell.html + src/js/*.js → brickmaster/index.html
```
`index.html`은 빌드 결과물이라 직접 고치지 않는다. 브라우저 콘솔의 `window.__bm`으로 상태 확인, 틱 진행, 강제 발사가 가능하다(밸런스 봇이 사용).

# BlockBot 설치·실행 가이드

폰에 설치되는 앱이 화면을 읽고, 놓을 자리를 표시하거나(힌트) 대신 둡니다(자동).
맥은 **설치할 때만** 필요합니다. 설치 후에는 케이블을 뽑아도 폰 혼자 동작합니다.

준비물: 맥(M1/M2), 갤럭시(Android 11 이상), **데이터 전송이 되는** USB-C 케이블, 인터넷

---

## A. 폰 설정 (처음 한 번)

1. **개발자 옵션 켜기**
   설정 → 휴대전화 정보 → 소프트웨어 정보 → **빌드번호**를 7번 연속 탭 → 잠금 PIN 입력
   → "개발자 모드를 켰습니다" 메시지
2. **USB 디버깅 켜기**
   설정 → (맨 아래) 개발자 옵션 → **USB 디버깅** 켜기 → 확인
3. **자동 차단 끄기** (One UI 6 이상에만 있음)
   설정 → 보안 및 개인정보 보호 → **자동 차단** → 끄기
   (켜져 있으면 USB로 앱 설치·설정 변경이 막힙니다)

## B. 맥 준비 (처음 한 번)

1. **터미널 열기**: `⌘ + Space` → "터미널" 입력 → 엔터
2. **Homebrew 설치** (이미 있으면 건너뛰기, `brew -v`로 확인)
   ```bash
   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
   ```
   맥 비밀번호를 물으면 입력(화면에 안 보이는 게 정상). 끝나면 화면의 **"Next steps"에 나온 두 줄을 그대로 복사해 실행**해야
   `brew` 명령이 잡힙니다. (Android Studio가 이미 설치돼 있다면 Homebrew는 없어도 됩니다)
3. **코드 받기**
   ```bash
   git clone -b ccr-58ce0f7a-mnq6uy https://github.com/sangwoan/Flash-game.git ~/Flash-game
   ```
   git을 처음 쓰면 "명령어 라인 개발자 도구 설치" 창이 뜹니다 → 설치 → 끝나면 위 명령을 다시 실행.

Java, Android SDK, adb는 따로 설치하지 않아도 됩니다. 아래 실행 스크립트가 없으면 자동으로 설치합니다.

## C. 연결하고 실행 (설치·업데이트할 때마다 같은 방법)

1. 폰을 케이블로 맥에 연결
2. 폰에 **"USB 디버깅을 허용하시겠습니까?"** 팝업 → "이 컴퓨터에서 항상 허용" 체크 → **허용**
   (팝업이 안 뜨면 상단 알림창의 USB 알림 → "파일 전송"으로 바꿔 보기)
3. 맥 터미널에서:
   ```bash
   bash ~/Flash-game/blockbot/mac/run.sh
   ```
   또는 Finder에서 `Flash-game/blockbot/mac/BlockBot 설치·실행.command` 더블클릭
   (처음 열 때 "확인되지 않은 개발자" 경고가 뜨면 우클릭 → 열기)
4. 스크립트가 순서대로 진행합니다:
   `Java 확인 → Android SDK 확인 → 폰 연결 확인 → 앱 빌드·설치 → 접근성 켜기 + 실행`
   **첫 실행은 내려받을 게 많아 5~10분**, 이후엔 1분 안팎입니다.
5. `완료!`가 나오면 폰에 BlockBot 설정 화면이 뜨고, 블록 게임이 설치돼 있으면 자동으로 열립니다.
   이제 케이블을 뽑아도 됩니다.

## D. 폰에서 사용

- 게임 화면 위쪽에 **[힌트] [자동] [정지]** 패널이 뜹니다.
  - 패널은 오른쪽 `⠿`를 끌어서 옮길 수 있습니다. **점수가 있는 위쪽**에 두세요.
    보드·블록 영역이나 화면 왼쪽 가장자리 아래쪽에 두면 인식이 흐트러질 수 있습니다.
- **힌트**: 놓을 자리를 칸 테두리로 표시합니다. ① 분홍 → ② 하늘 → ③ 노랑 순서.
  직접 드래그해서 두면 다음 수를 다시 계산합니다. 패널 글자에 "①슬롯2 ②슬롯1…"처럼 어느 블록인지도 나옵니다.
  - 계산은 이번 블록 3개의 모든 순서·위치 + **다음 라운드에 나올 블록을 24번 가정한 수읽기**까지 합니다(최대 약 1.5초).
  - 패널의 "다음 판 생존 xx%"는 추천대로 뒀을 때 다음 라운드 블록 3개를 모두 놓을 수 있을 확률 추정치입니다.
- **자동**: 봇이 직접 드래그합니다.
  - 처음 2~3수는 손가락과 블록 사이 간격을 스스로 맞추느라 **한두 칸 빗나갈 수 있습니다**(그 뒤로 학습된 값 사용).
  - 드래그가 계속 반영되지 않으면 스스로 힌트 모드로 바꿉니다.
  - 게임이 아닌 다른 앱으로 넘어가면 드래그하지 않고 기다립니다.
- **정지**: 모든 동작 중지.
- 설정 화면(앱 서랍의 BlockBot 아이콘): 콤보 규칙, 자동 속도, 드래그 보정 초기화, 스크린샷 저장 여부.

## E. 패턴 학습 (플레이할수록 강해지게)

앱은 매 라운드 실제로 나온 블록과 보드를 기록합니다. 몇 판 플레이한 뒤 폰을 연결하고:

```bash
bash ~/Flash-game/blockbot/mac/learn.sh          # 블록 출현 패턴 학습 (1~2분)
bash ~/Flash-game/blockbot/mac/learn.sh --tune   # + 가중치 자가대국 튜닝 (약 20분)
```

- **블록 출현 패턴**: 어떤 블록이 얼마나 자주 나오는지, 게임이 "들어갈 블록"을 얼마나 골라 주는지(관대함)를 학습해
  다음 라운드 수읽기에 반영합니다. 이전 버전 앱의 로그도 그대로 씁니다.
- **가중치 튜닝**: 학습한 패턴으로 수천 판을 자가대국하며 보드 평가 기준(구멍·울퉁불퉁함·콤보 유지 등)을 최적화합니다.
  기존보다 나을 때만 저장합니다.
- 끝나면 결과가 폰에 올라갑니다. 게임에서 [정지] → [힌트]를 누르면 적용됩니다. 설정 화면 "학습 상태"에서 확인할 수 있습니다.

## F. 자동 모드의 드래그 학습

자동 모드는 한 수 둘 때마다 "손가락을 뗀 위치 → 블록이 실제로 놓인 칸"을 기록해
**이동 배율(손가락보다 블록이 더/덜 움직이는 정도)과 띄움 높이**를 다시 계산합니다.
처음 2~4수는 빗나갈 수 있지만 그 뒤로는 정확해집니다. 학습값은 폰에 저장되어 다음에도 유지됩니다.
드래그도 사람 손처럼 "집기 → 빠르게 → 도착 직전 천천히 → 잠깐 멈춤 → 떼기"로 바꿨습니다.
계속 빗나가면 설정 화면의 "드래그 학습 초기화" 후 다시 시도하고, 로그를 보내 주세요.

## G. 업데이트

```bash
cd ~/Flash-game && git pull && bash blockbot/mac/run.sh
```

## H. 문제 해결

| 증상 | 해결 |
|---|---|
| 3단계에서 "폰이 안 보입니다" | 케이블이 충전 전용일 수 있음 → 다른 케이블. USB 디버깅 켜짐 확인. 폰 잠금 해제 상태에서 연결 |
| "허용 팝업" 안내가 반복 | 폰 화면을 켜고 팝업에서 허용. 안 보이면 개발자 옵션 → "USB 디버깅 권한 승인 취소" 후 케이블 다시 꽂기 |
| 4단계 설치 실패 | 자동 차단(A-3) 끄기 |
| 패널이 안 보임 | BlockBot 설정 화면에서 접근성 상태 확인 → 꺼져 있으면 "접근성 설정 열기" → 설치된 앱 → BlockBot → 켜기 |
| "제한된 설정" 때문에 접근성을 못 켬 | 설정 → 애플리케이션 → BlockBot → ⋮ → "제한된 설정 허용" 후 다시 켜기 |
| "보드를 찾는 중…"이 계속 | 광고·메뉴 화면인지 확인. 게임 보드 화면에서도 계속되면 로그를 보내 주세요 |
| 자동 드래그가 엉뚱한 곳에 놓임 | 처음 2~4수는 학습 중. 계속되면 설정 화면 → 드래그 학습 초기화, 자동 속도 "느림" |
| 한참 쓰다 패널이 사라짐 | 설정 → 애플리케이션 → BlockBot → 배터리 → "제한 없음" |

**피드백 보내기 (권장)**: 폰을 연결한 상태에서 `bash ~/Flash-game/blockbot/mac/feedback.sh` →
바탕화면에 `blockbot-feedback-날짜` 폴더가 열립니다. 안의 사진(📷 신고, 드래그 실패 등)과 summary.txt를 대화창에 끌어다 놓아 주세요.
(저장소가 공개라서 스크린샷은 GitHub에 올리지 않습니다)

**로그 보내기**: 폰을 연결한 상태에서 `bash ~/Flash-game/blockbot/mac/pull-logs.sh` 를 실행하면
`blockbot/logs-from-phone/`에 기록(JSONL)과 문제 상황 스크린샷이 저장됩니다. 이 폴더를 대화에 올려 주시면 됩니다.
실시간으로 보려면 `bash ~/Flash-game/blockbot/mac/watch.sh`

## 알아둘 점

- **자동 플레이는 대부분 게임 약관 위반**이며 계정 제재 위험이 있습니다. 힌트 모드는 화면을 보고 표시만 합니다.
- 인식은 실제 스크린샷 5장(테마 5종, 해상도 2종)으로 검증했고, 전체 루프는 합성 화면으로 검증했습니다.
  **실기기에서 확인되지 않은 부분**: 게임이 접근성 드래그를 받아들이는지, 드래그 오프셋 초깃값,
  처음 보는 테마·블록 모양. 문제가 생기면 로그를 보내 주세요.

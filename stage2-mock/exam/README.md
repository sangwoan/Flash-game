# 통근버스 좌석 배정 서비스

> 2차 예선 모의 과제입니다. 이 폴더(README.md와 data/)가 시험 시작 때 열려 있는 최상위 폴더라고 생각하고 진행하세요.

## 1. 배경

한결반도체 청주 캠퍼스 총무팀은 매달 통근버스 좌석 신청을 받아 직원별로 버스와 좌석을 배정합니다. 지금까지는 담당자가 엑셀로 손수 배정했는데, 지난달에는 "만석이라 못 탔다"는 민원이 20건 넘게 들어왔습니다. 11월에는 노선 개편까지 겹쳐서, 총무팀은 다음을 원합니다.

- 직원이 사번만 넣으면 자기 버스, 탑승 정류장, 탑승 시각, 좌석을 볼 수 있을 것
- 정원을 넘기지 않으면서도 못 타는 사람을 최대한 줄일 것
- 못 타는 사람에게는 이유와 대안을 알려 줄 것

여러분은 11월 신청서(`data/applications.csv`)로 배정 결과를 만들고, 조회 서비스를 만듭니다.

## 3. 요구사항 (R)

| ID | 요구사항 |
|---|---|
| R1 | 직원이 사번을 입력하면 자기 배정 결과를 화면에서 볼 수 있다. |
| R2 | 배정된 직원에게는 노선, 버스, 탑승 정류장, 그 정류장의 탑승 시각을 보여 준다. |
| R3 | 신청한 직원 전원에게 배정 결과(배정 또는 미배정)가 있어야 한다. |
| R4 | 버스별 정원을 관리한다. |
| R5 | 배정된 직원에게 좌석 번호를 준다. |
| R6 | 관리자는 버스별 탑승 인원과 정원을 한눈에 볼 수 있다. |
| R7 | 1지망에 못 탄 직원은 다른 방법으로 최대한 태워서, 버스를 못 타는 사람을 줄인다. |
| R8 | 배정 결과를 CSV 파일로 내보낸다 (형식은 5장). |
| R9 | 버스를 못 타는 직원에게는 사유와 대안을 보여 준다. |
| R10 | 11월 노선 개편(`route_update.md`)을 반영한다. |

## 4. 조건 (C)

| ID | 조건 |
|---|---|
| C1 | 직원은 자기 근무조의 버스에만 탈 수 있다. |
| C2 | 탑승 정류장은 배정된 노선(개편 후)이 지나는 정류장이어야 한다. |
| C3 | 1지망 버스에 신청자가 정원보다 많으면 다음 순서로 태운다. ① 교통약자 ② 지난달 「만석 미탑승」 민원을 낸 직원 ③ 신청 시각이 빠른 직원 ④ 사번이 빠른 직원. 1지망 배정을 모두 마친 뒤에야 다른 방법(R7)으로 남은 자리를 채울 수 있다. 다른 방법으로 배정된 사람이 1지망 신청자의 자리를 차지하면 안 된다. |
| C4 | 좌석 1~4번은 교통약자 우선석이다. 교통약자는 1~4번부터, 일반 직원은 5번부터 배정한다. 5번 이후가 모두 차면 남은 1~4번을 일반 직원에게 줄 수 있다. 한 버스 안에서 좌석 번호는 겹칠 수 없다. |
| C5 | 1지망이 아닌 버스에 배정할 때(2지망 또는 다른 노선), 탑승 정류장은 신청서의 탑승 정류장이거나 직원 집 정류장에서 직선거리 2km 이내여야 한다. |
| C6 | 미배정 사유는 다음 코드 중 하나로 표시한다. `FULL`(정원 초과), `NO_SHIFT_BUS`(신청 노선에 그 근무조 버스가 없음), `STOP_NOT_ON_ROUTE`(신청 노선이 탑승 정류장을 지나지 않음), `INVALID`(신청서 오류). 배정은 `OK`(1지망) 또는 `ALT`(1지망이 아닌 버스). |
| C7 | 신청서 예외: ① 같은 사번이 여러 번 신청했으면 신청 시각이 가장 늦은 신청만 유효하다. ② 직원 명단에 없는 사번, 존재하지 않는 노선을 1지망으로 쓴 신청은 `INVALID`. ③ 폐지 노선 신청자는 `route_update.md` 5항대로 처리한다. ④ 교통약자 여부는 `employees.csv`의 `mobility` 열로만 판단한다(신청서 메모는 쓰지 않는다). |
| C8 | `README.md`와 `data/`는 수정하지 않는다. 같은 입력이면 언제 실행해도 같은 결과가 나와야 한다. |

## 5. 제출물

### 5-1. 배정 결과 파일 `output/assignments.csv`

신청한 사번마다 한 줄. UTF-8, 첫 줄은 아래 열 이름 그대로.

```
emp_id,status,route_id,bus_id,board_stop,board_time,seat_no,reason_code,alternative
E1003,배정,R2,B-R2-D,S01,07:38,12,OK,
E1150,배정,R3,B-R3-D,S10,07:48,30,ALT,1지망 만석으로 2km 이내 서부선 배정
E1210,미배정,,,,,,FULL,대기자 등록. 자차 통근 지원금 신청 가능
```
(값은 예시입니다)

- `status`: `배정` 또는 `미배정`
- `board_stop`: 정류장 ID (예: `S01`)
- `board_time`: `HH:MM`. 캠퍼스 도착 시각에서 그 정류장부터 캠퍼스까지의 소요 시간을 뺀 값
- 미배정이면 노선·버스·정류장·시각·좌석은 비우고, `reason_code`와 `alternative`(대안 안내 문구)를 채운다

### 5-2. 조회 서비스

`python app/main.py`로 실행하면 `http://localhost:8000`에서 동작해야 한다.

| 주소 | 동작 |
|---|---|
| `GET /` | 사번을 입력해 결과를 보는 화면 (R1, R2, R9) |
| `GET /api/assignment?emp_id=E1003` | 그 사번의 결과를 JSON으로. 키는 5-1의 열 이름과 같고 값도 결과 파일과 같아야 한다. 신청 내역이 없는 사번은 HTTP 404 |
| `GET /api/summary` | 버스별 현황 JSON 배열. 각 항목에 `bus_id`, `assigned`(탑승 인원), `capacity` (R6) |

Python 표준 라이브러리만으로도 만들 수 있습니다. 외부 패키지를 쓰면 `requirements.txt`에 적으세요.

## 1. 북부선(R4) 폐지
- 이용객 감소로 북부선(R4) 운행을 종료합니다. 버스 B-R4-D, B-R4-A는 운행하지 않습니다.

## 2. 중앙선(R2) 기점 연장

- 변경: **율량동 → 내덕동 → 시청** → 법원 → 사창사거리 → 봉명동 → 캠퍼스
- 추가 구간 소요 시간: 율량동 → 내덕동 6분, 내덕동 → 시청 7분 (이후 구간은 기존과 같음)

## 3. 오송선(R5) 기점 연장
- 기존: 오송역 → 강서동 → 캠퍼스
- 변경: **오창 → 오송역** → 강서동 → 캠퍼스
- 추가 구간 소요 시간: 오창 → 오송역 22분

## 4. 차량 교체
- 서부선 A조 버스(B-R3-A)를 대형(45석)에서 중형(28석)으로 교체합니다.

## 5. 북부선 신청자 처리
- 이미 북부선(R4)으로 신청한 직원은 다시 신청하지 않아도 됩니다.
- 탑승 정류장이 율량동·내덕동이면 중앙선(R2), 오창이면 오송선(R5)으로 신청한 것으로 봅니다.
- 그 밖의 내용(근무조, 탑승 정류장, 신청 시각)은 원래 신청서를 그대로 따릅니다.

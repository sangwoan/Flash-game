# 서술형 채점 기준 (연습을 마친 뒤에 보세요)

각 문항 0~3점. 3점 = 규칙 + 수치 + 확인 방법이 모두 있음.

1. 우선순위: 교통약자(employees.csv mobility만) → 「만석 미탑승」 민원자(다른 유형 제외) → 유효 신청(마지막 신청)의 신청 시각 → 사번. 1지망을 모두 처리한 뒤 대체 배정.
2. 기본 데이터 기준 1지망만: 55명 → 2지망·2km 대체 후: 44명. C5(2km)와 C3(1지망 자리 침범 금지)를 지킴. 수치 없이 "줄었다"만 쓰면 1점.
3. 율량동·내덕동 → R2, 오창 → R5로 1지망 전환. 그 외 정보는 원 신청서 유지. 확인: R4 신청자 수(43명) 중 INVALID 0명, R4 버스 배정 0명.
4. 자동 검사(정원 초과 0, 근무조 불일치 0, 경유 정류장 위반 0, 좌석 중복 0, 우선순위 위반 0) + 지표(미탑승 수) + 화면에서 사번 3종(배정/대체/미배정) 직접 조회. 확인 못 한 것: 예) 대안 문구의 적절성은 사람이 봐야 함.
5. 기본 데이터 기준: B-R2-D에서 17명이 내려야 함 → 그중 6명은 2지망·2km 대체로 다른 버스 배정, 11명은 미배정. 전체 미탑승 44 → 55명. 교통약자·만석 민원자 중 영향받은 사람은 0명(우선순위가 높아 남음).
6. 근거 있는 한 가지 (예: 대기자 순번 공개, 퇴근 버스, 2km 기준을 도보 시간으로).
